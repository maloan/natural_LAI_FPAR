# Generated Outputs

This folder contains products generated by the managed-land masking workflow for LAI and FPAR.

Outputs are organized by scenario:

```text
output/
├── alpha_0.05/
├── alpha_0.1/
├── alpha_0.2/
├── glc/
└── chapter2/
```

The three `alpha_*` directories correspond to CCI managed-land thresholds. The GLC-based branch is stored once under `glc/`. It uses the shared CCI-derived nonvegetated mask stored under `alpha_0.1/masks/mask_nonvegetated/`. The unmasked baseline is stored separately under `analysis/unmasked/`.

## Scenario contents

The `alpha_*` and `glc/` scenario directories contain:

- `masked_0p05/` with monthly masked LAI and FPAR at 0.05° resolution.
- `masked_0p25/` with area-weighted monthly products at 0.25° resolution.
- `masks/` with land-use, pasture-overlap, and non-vegetated masks.
- `eval/` with trend and diagnostic products used by downstream analyses.

Binary masks use:

```text
1  = exclude
0  = retain
NA = undefined
```

## Chapter 2 products

`output/chapter2/` contains derived 0.5° inputs for subsequent analyses:

- `fpar_unmasked_0p5_monthly_1982-2024.nc`
- `mask_CCI_alpha0p10_pasture_any_0p5.nc`
- `mask_CCI_alpha0p10_pasture_excluded_fraction_0p5.tif`
- `fpar_masked/fpar_masked_0p5_monthly_1982-2024.nc` (separate CCI alpha 0.1 plus pasture masked fAPAR)

These products are generated by the complete workflow.
